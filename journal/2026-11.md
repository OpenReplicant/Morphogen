## 2026-11-01: v0.2.1, review pass

- **Gap:** a review found ways round the frame:
  - shell writes to locked files with no path in the command (`git apply`,
    scripts) or with `&>`
  - direct commits and ref moves on the trunk
  - `.claude/settings.local.json` or `~/.claude/settings.json` turning hooks off
  - git config and hooks that would run code on the host
  - candidates redefining an existing `cmd:` KPI
  - trial budgets dodged by running the gate from a script
  - `git merge-base` crashing the guard
- **Choice:**
  - The guard snapshots locked files and the trunk before each shell command,
    and undoes changes afterwards (stray trunk commits are kept on
    `rescued/*`).
  - Trunk protection; more deny rules.
  - The gate takes KPI definitions from the base, counts the trial budget
    itself, and has a `--repo` option.
  - Read-only devcontainer mounts for the judge, guard, sandbox and git
    hooks/config.
  - A CI gate workflow for branch protection.
  - Generated map files are no longer committed.
  - A session briefing and a status line for the operator.
- **Why:** each layer is weaker alone. Patterns are cheap, but scripts evade
  them. The snapshot catches what the patterns miss. Read-only mounts protect
  the guard itself, and CI protects the trunk when the agent has shell access.
- **Rung:** generate. These are operator-owned parts.
- **Gate:** not applicable (no Morphogen trunk yet in this repo); scenarios
  tested in a throwaway repo.

## 2026-11-02: plugin judge hardened

- **Gap:** a probe showed the plugin's judge passed a candidate that kept the
  slow algorithm and patched `time.perf_counter` (in-process timing). Review
  found more: seeds stored in a file the agent could read; candidates could
  shadow standard modules; the trial budget was not enforced; and, while
  testing, the evidence log in the working tree was swept into candidate
  commits by `git add -A` and lost on branch switches. An A/A test (identical
  code) passed 2 of 12 times.
- **Options:** for timing, trust printed numbers with checks, or time from
  outside the process (chosen). For noise, more runs with a bootstrap on
  medians, or paired ABBA rounds with a sign test (chosen after the A/A test).
  For evidence, commit it, or keep it in git's common directory (chosen).
- **Choice:** wrapper process times the run and reads its resource usage
  (`wall_seconds`, `cpu_seconds`, `max_rss_kb`); printed metrics are
  "reported" and cannot be primary. Fresh random seeds per run, recorded
  afterwards. Candidates may not add files shadowing standard modules,
  `sitecustomize` or `.pth`. Paired ABBA rounds, median paired gain plus sign
  test at p <= 0.01, 10 to 30 rounds. `trials_per_day` enforced. Evidence in
  `.git/morphogen/`. Red-team suite of ten known cheats, all failing.
- **Result:** A/A false passes 0 of 12 (mean bias +0.5%); a real speed-up
  passed 5 of 5; 20 tests pass twice through `uv`. Run directly in this
  container (no Docker).
- **Rung:** generate (judge code); reused the sign test, ABBA ordering and
  `os.wait4` resource accounting.
- **Gate:** see archive tag from this commit's gate run.
